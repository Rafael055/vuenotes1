Quick setup

  1. Add Vue with a CDN script or install it in a project.
  2. Create an app with Vue.createApp(...).
  3. Mount it on a root element like #app.
  4. Use directives in the template to make the page reactive.

Common Vue notes

  • v-if: conditionally renders content. It is not a loop.
  • v-else / v-else-if: companion conditions for v-if.
  • v-for: loops through arrays or objects and renders repeated items.
  • v-bind: binds an attribute like src, href, or class.
  • v-model: creates two-way binding for inputs and forms.
  • @click / v-on: listens for events like clicks, input, or submit.
  • computed: derives values from reactive data.
